## 3. Проверка системы

Для сборки приложения использована команда:

```bash
docker build -f lab/Dockerfile -t devops-student:v1 lab
```

Для запуска:

```bash
docker compose -f compose.student.yaml --profile monitoring up -d
```

Для Ansible:

```bash
docker compose -f compose.student.yaml run --rm ansible banner.yml
```

Приложение доступно на порту 8080, мониторинг — на портах 9090 и 3000.

## 4. Связь компонентов

Исходный код проходит автоматические тесты в GitHub Actions. После успешных тестов собирается Docker-образ.

Web направляет запросы на API через внутреннюю сеть Docker. Данные сохраняются в именованном томе requests.

Prometheus собирает метрики, Grafana строит графики. При сбое метрики показывают проблему, а логи помогают установить причину.
