# K3-05 — Разбор ошибки pipeline

Группа: ИТ-9.24.2  
Код студента: 12072008

## 1. Цель работы

Научиться определять причину ошибки в GitHub Actions по логам, исправлять её и повторно проверять работу CI.

## 2. Воспроизведение ошибки

В файле `.github/workflows/student-ci.yml` намеренно изменён путь к Dockerfile.

Правильная команда:

```bash
docker build -f lab/Dockerfile -t devops-student:${{ github.sha }} lab
```

Команда с ошибкой:

```bash
docker build -f lab/MissingDockerfile -t devops-student:${{ github.sha }} lab
```

Файл `lab/MissingDockerfile` отсутствует в проекте.

## 3. Неуспешный запуск

Ссылка: https://github.com/spaeeell/DevOps-course/actions/runs/42379047304

Событие: push  
Commit SHA: `21f1dbc27511f9114508b1155cfaa7351dfb2d21`

Результат:

- test — success
- build — failed

В логе шага Build Docker image обнаружена ошибка:

```text
ERROR: failed to build: failed to solve: failed to read dockerfile: open MissingDockerfile: no such file or directory
```

Причина ошибки: Docker не смог найти файл, указанный параметром `-f`.

Тесты приложения прошли успешно. Ошибка возникла только во время сборки Docker-образа.

## 4. Исправление

Путь к Dockerfile восстановлен:

```bash
docker build -f lab/Dockerfile -t devops-student:${{ github.sha }} lab
```

После исправления создан новый коммит и повторно запущен Student CI.

Ссылка: https://github.com/spaeeell/DevOps-course/actions/runs/42379318151

Событие: push  
Commit SHA: `0258ccef309a6759df917ffe9c957c1d52d84e98`

Результат:

- test — success
- build — success

Таким образом, исправление подтверждено успешным выполнением обоих jobs.

## 5. Вывод

В ходе работы была воспроизведена и исправлена ошибка сборки Docker-образа.

В отличие от ошибки тестирования, ошибка отсутствующего Dockerfile возникает непосредственно на этапе сборки, поэтому job test может завершиться успешно, а job build — неуспешно.

GitHub Actions позволяет определить проблемный шаг, прочитать сообщение об ошибке и проверить исправление в новом запуске.

При подготовке отчёта использована помощь ИИ для оформления и объяснений. Результаты сверены с фактическими логами GitHub Actions.
