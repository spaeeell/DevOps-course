# Работа K2-05



- Группа: ИТ-9.24.2

- Код студента: 12072008

- Что сделано: В `compose.student.yaml` у сервиса `web` был временно указан неправильный адрес API `http://api:9999`. После запуска была воспроизведена ошибка связи между `web` и `api`. Затем порт был исправлен на `8000`, после чего работа приложения восстановилась.



- Команды и существенный вывод:



```powershell

docker compose -f compose.student.yaml up -d web

docker compose -f compose.student.yaml logs web

docker compose -f compose.student.yaml ps

```



Для воспроизведения ошибки использовалась настройка:



```yaml

API_URL: http://api:9999

```



После этого приложение показало отсутствие связи с сервисом заявок. Список заявок не загружался, а отправка заявки не подтверждалась.



После исправления настройки:



```yaml

API_URL: http://api:8000

```



сервис `web` был запущен повторно. Список заявок снова стал доступен.



После восстановления связи отображались ранее созданные заявки №1, №2 и №3, а новая заявка №4 успешно создалась.



- Ожидал: При неправильном порте `9999` сервис `web` не сможет обратиться к `api`. После возврата правильного порта `8000` работа должна восстановиться.



- Получил: При `9999` связь с API отсутствовала. После возврата `8000` список заявок снова загрузился, и заявка №4 была успешно принята.



- Почему это подтверждает результат: Ошибка была вызвана именно неправильным внутренним портом API. После исправления только этого значения связь между контейнерами восстановилась.



- Ошибка и её исправление: Во время редактирования YAML также были нарушены отступы, из-за чего `docker compose config` показывал ошибку структуры. Отступы были исправлены, после чего конфигурация снова стала валидной.



- Ответ на вопрос из задания: Между контейнерами нужен порт `8000`, потому что `api` слушает порт `8000` внутри Docker-сети. Порт `8080` используется только для доступа с компьютера пользователя к сервису `web`.



- Использованные источники и помощь, в том числе ИИ: Использован репозиторий курса DevOps и помощь ChatGPT для поиска ошибки в YAML, пояснения портов Docker Compose и оформления отчёта. Все команды и проверки выполнены вручную.
