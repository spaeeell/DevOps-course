## Проверка шагов

- `actions/checkout` — получает файлы репозитория на runner.
- `actions/setup-python` — устанавливает выбранную версию Python.
- `python --version` — выводит Python 3.13.18.

Job — отдельная задача workflow, выполняемая на runner. Step — конкретный шаг внутри job.

## Вывод

Workflow успешно запускается автоматически после отправки изменений.

Однако успешная команда `python --version` не доказывает, что приложение работает. Она проверяет только доступность Python. Для проверки самого приложения необходимо добавить запуск тестов.

При подготовке отчёта использована помощь ИИ для оформления и объяснения; фактические результаты сверены с GitHub Actions.
