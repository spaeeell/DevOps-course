- Получил: Образ успешно собрался, контейнер запустился, `/health` вернул HTTP 200. В `docker image inspect` отображаются правильные USER, CMD, WORKDIR, порт и LABEL.



- Почему это подтверждает результат: Dockerfile используется для сборки собственного образа приложения. Контейнер был создан именно из образа `devops-student:v1`, успешно запустил приложение и обработал health-запрос.



- Ошибка и её исправление: Изначально файл Dockerfile был сохранён как `Dockerfile.txt`, поэтому Docker не мог его найти. Файл был переименован командой:



```powershell

Rename-Item .\lab\\Dockerfile.txt Dockerfile

```



После этого сборка прошла успешно.



- Ответ на вопрос из задания: `EXPOSE 8000` только указывает, какой порт приложение использует внутри контейнера. Он не публикует этот порт на компьютере. Для доступа с компьютера используется `-p`, например:



```text

-p 127.0.0.1:8081:8000

```



Здесь порт `8081` находится на компьютере, а `8000` — внутри контейнера.
