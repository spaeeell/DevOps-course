## 1. Что выполнено

В `.github/workflows/student-ci.yml` добавлен отдельный шаг автоматического тестирования:

```bash
python -m unittest discover -s tests -p test_app.py -v
```

Тесты запускаются в GitHub Actions при отправке изменений в репозиторий.

Проверяется работа приложения, в том числе создание заявки, обработка ошибочных запросов и восстановление работы API.

## 3. Намеренная ошибка

В файле `tests/test_app.py`, в функции `test_create_request`, временно изменено ожидаемое значение HTTP-статуса:

Было:

```python
self.assertEqual(status, 201)
```

Стало:

```python
self.assertEqual(status, 200)
```

Приложение при успешном создании заявки возвращает статус `201 Created`. Тест ожидал `200 OK`, поэтому проверка завершилась ошибкой.

Неуспешный запуск Student CI:

https://github.com/spaeeell/DevOps-course/actions/runs/42375695317

Событие: push  
Commit SHA: `276bb5149c288f81154e852ad7db4dfd2837cd60`  
Результат: failure

Фрагмент лога:

```text
FAIL: test_create_request
AssertionError: 201 != 200
Ran 7 tests in 0.991s
FAILED (failures=1)
```

Шесть тестов прошли успешно, один завершился ошибкой.

Причина: неверное ожидаемое значение в тесте. Само приложение продолжало правильно возвращать HTTP 201.

## 4. Исправление

В тесте восстановлено исходное ожидание:

```python
self.assertEqual(status, 201)
```

После этого создан новый коммит и повторно запущен Student CI.

Успешный запуск:

Событие: push  
Commit SHA: `9536d4f88caab44f59327dafe1965de4e8461ff9`  
Результат: success

Все тесты прошли успешно.

## 5. Вывод

В работе был настроен автоматический запуск реальных тестов приложения.

Намеренно неверное ожидание HTTP-статуса вызвало ошибку тестирования, и GitHub Actions отметил запуск красным.

После восстановления правильного значения повторный запуск завершился успешно.

Таким образом, CI работает как тестовый барьер и помогает обнаруживать несоответствия до принятия изменений.

При подготовке отчёта использована помощь ИИ для оформления и объяснений. Результаты проверены по собственным запускам GitHub Actions.
